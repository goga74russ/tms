### Что было сделано

1. **Переписаны генераторы под реальную структуру ФНС** (было: упрощённый макет
   `<СведТранспортнойНакладной>/<СвУчаст>/<Отправитель>` — отклонялся любым
   оператором). Теперь — корректные `<Документ КНД>/<СодИнфГО>/<СвГО>/<СвГП>/
   <СвПер>/<СвГруз>/<СвТС>/<СвВодит>/<СвПогруз>/<Подписант>` и т.д.
2. **Тонкие ссылочные титулы 2/5/6** — ссылаются на файл предыдущего титула через
   его ЭП (Т2→Т1, Т5→Т2, Т6→Т5), как требует приказ. Не дублируют участников.
3. **Структурный валидатор + гейт** (`xsd-validator.ts`, `xsd-validator-gate.ts`)
   приведены к ФНС-структуре: распознавание титула по КНД, проверки по новым
   именам элементов.
4. **Дисциплина «не подставляем фиктивные данные»**: отсутствие обязательного
   по XSD поля → `EtrnIncompleteError` → 422 с именем поля (а не выдуманное
   значение). См. `etrn-generator.ts`.

## Архитектурное следствие: цепочка ЭП

Титулы 2/5/6 структурно валидны с **placeholder-ЭП** (`SIGNATURE_PLACEHOLDER`),
но юридически замыкаются только после реального КЭП-подписания предыдущего титула.
Подписание подключается вместе с оператором (**Контур** — ключи ожидаются).
До этого: XSD-структура верна, подпись — заглушка.

## Пробелы сбора данных в TMS (endpoint `/waybills/:id/etrn` → 422)

XSD требует поля, которых в модели TMS пока нет или нет на конкретной записи —
endpoint честно отдаёт 422, а не фиктив:

- **Телефон водителя** (`СвВодит/Тлф`, обязателен) — в `drivers` колонки нет,
  берём из `users.phone` через `drivers.userId`. Нет привязки/телефона → 422.
- **Телефон грузоотправителя** (`СвПА/КонтПА/Тлф`, обязателен) — `contractors.phone`.
- **Места груза** (`КолМестГр/КолМестПрием`) — `orders.cargoPlaces` (nullable).
- **Номер/дата заказа** (`НомЗак/ДатаЗак`) — `orders.number` / `orders.loadingDate`.
- **Факты погрузки** (`СвПогруз`: `ЗаявПогр/ФДатВрПриб/ФДатВрУбыт`) — TMS не
  фиксирует отдельно фактические прибытие/убытие под погрузку. Для предпросмотра
  используется плановое `orders.loadingDate`; **перед юр-отправкой через ЭДО
  заменить на фактические события погрузки** (TODO: захват loading-events).
- Телефон участников (СвГО/СвГП/СвПер, `Контакт/Тлф`) **обязателен по XSD**
  (`УчастникТрНТип` всегда требует `<Контакт>`; `<Адрес>` его не заменяет —
  BUG-EPD-01). Источники: грузоотправитель/получатель — `contractors.phone`,
  перевозчик — телефон пользователя-инициатора (`users.phone`). Нет → 422.

  (главный путевой лист + медосмотры/техконтроль/одометр как отдельные документы).

Проверяется `validateXmlAgainstSchema` (xmllint-wasm), зафиксировано в

Эндпоинт `/orders/:id/ezz` формирует первичную заявку ГРУЗООТПРАВИТЕЛЯ (969_01)
