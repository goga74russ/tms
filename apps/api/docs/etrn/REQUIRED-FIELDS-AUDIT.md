## Не master-data (не делаем «обязательным у роли»)

Захватывается при формировании документа / per-trip:
- Факты погрузки (`СвПогруз`: заявл./факт. прибытие-убытие) — события рейса.
- Одометр выезд/заезд (ЭПЛ) — `waybills.odometerOut/In`.
- ЭП цепочек титулов/ЭЗЗ/ЭПЛ — placeholder до КЭП (Контур).
- Лицензия медорганизации (ЭПЛ-медосмотры) — только алко-ниша, сущности нет.

## Фазы

- **Фаза 1 (миграция 0059, готово):** добавлены недостающие колонки (additive,
  nullable). Генераторы (`/etrn`, `/epl`, `/orders/:id/ezz`) пробрасывают их:
  телефон перевозчика — `organizations.phone` → инициатор; телефон/серия/дата ВУ/ИНН
  водителя — из `drivers`; габариты — из `orders`.
- **Фаза 2 (валидация форм):** сделать поля обязательными при создании/редактировании
  соответствующих сущностей — на уровне приложения (Zod + формы), НЕ DB `NOT NULL`
  (чтобы не ломать существующие строки и прод-данные).
- **Фаза 3 (опц.):** после бэкфилла legacy — `NOT NULL` на уровне БД.
