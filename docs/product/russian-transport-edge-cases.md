# Backlog операционных edge cases РФ

Обновлено: 2026-04-29

## UI coverage update 2026-04-29

- Done: web trip dossier now includes an operational actions panel for downtime, readdressing, cancellation after arrival, breakdown, and post-trip return.
- Checked: `corepack pnpm --filter @tms/web lint`, `scripts/ui-workflow-smoke.ps1`.
- Still later: resource replacement selector UI, crew-rest UI, printed acts, tariff rule engine, and real ETRN provider/KEP/MChD integration.

Этот список нужен, чтобы TMS v2 не стала системой только для happy path `одна заявка -> одна машина -> одна доставка`. Реальные перевозки часто ломают такую модель: груз делится, консолидируется, меняется по факту, требует особых условий, документов, разрешений или претензионного контура.

Колонка `Работа` используется как живой трекер: `сделано + дата` означает, что есть код/документация/проверка в `TMS-prod`; `частично` означает, что фундамент есть, но сценарий еще нельзя считать закрытым end-to-end.

## P1. Частые операционные сценарии

| Сценарий | Пример из жизни | Что должен уметь продукт | Сейчас | Работа |
|---|---|---|---|---|
| Одна заявка -> несколько рейсов | 100 тонн, машины по 20 тонн | Делить заказ на партии/сегменты, считать остаток, закрывать частями | Есть модель `shipment_lots`, `trip_lot_assignments`, read/write API, smoke 100 тонн -> 2 рейса | Сделано 2026-04-29; нужно UI и больше кейсов |
| Один рейс -> несколько заявок | Машина забирает 3 заказа у разных клиентов | Консолидировать партии, вести отдельные документы/статусы/биллинг по каждой заявке | `trip_orders`, route points и модель партий поддерживают несколько заказов в рейсе | Сделано бесплатно, проверено 2026-04-29: multi-order foundation есть; UI-группировка позже |
| Частичная погрузка | План 20 тонн, загрузили 18.7 | Фиксировать факт, причину, фото/подписи, пересчет остатка и тарифа | Есть `shipment_facts` по весу/объему/местам, evidence attachments, GPS, подпись, пересчет lot totals | Сделано бесплатно, проверено 2026-04-29: smoke покрывает фото/подпись/паллеты/evidence; тарифные правила позже |
| Частичная доставка | Получатель принял 17 из 18 паллет | Отразить недостачу, акт, claim, финансовый резерв | Есть фактическая разгрузка, shortage, акт/evidence, авто-претензия, reserve/estimated amount, финконтур допуслуг/оплат | Сделано бесплатно, проверено 2026-04-29: smoke на недовоз с актом и резервом |
| Мультистоп | Один рейс с несколькими погрузками/выгрузками | Последовательность точек, SLA по каждой точке, документы по каждой партии | Route points создаются при назначении партии, downtime/SLA факты пишутся по точке, cockpit видит исключения | Сделано бесплатно, проверено 2026-04-29; визуальный UI маршрута позже |
| Переадресация | Получатель/адрес меняются в пути | Версионировать маршрут, согласование, документальный след, ЭТРН-титул переадресовки | Есть API изменения route point, journal event, cockpit signal, ЭТРН Title 03 metadata | Сделано, проверено 2026-04-29; нужен UI согласования |
| Отмена после подачи ТС | Машина приехала, груз не готов | Фиксировать подачу, простой/штраф, акт, оплату | Есть API cancel-after-arrival, фиксация подачи, reserveAmount, journal event и cockpit signal | Сделано, проверено 2026-04-29; нужен печатный акт/UI |
| Простой на погрузке/выгрузке | Машина стоит 8 часов на складе | Тайминг прибытия/убытия, норматив, начисление, доказательства | Есть API downtime по route point, waiting/billable minutes, reserveAmount, journal event и cockpit signal | Сделано, проверено 2026-04-29; нужны тарифы начисления |
| Замена машины/водителя | Поломка, заболел водитель, другой тягач | История замен, перепроверка готовности, обновление документов | Есть API замены ТС/водителя/прицепа, compatibility recheck, journal event, cockpit signal, ЭТРН Title 04 metadata | Сделано, проверено 2026-04-29; нужен UI согласования |
| Поломка в пути | Рейс не может продолжаться | Инцидент, эвакуация/ремонт, перегруз в другую машину, уведомления | Есть API breakdown, blocking cockpit signal, nextActions на ремонт/замену ресурса | Сделано, проверено 2026-04-29; нужна связка с repair UI |
| Возврат груза | Получатель отказался или часть возвращается | Обратный рейс/сегмент, новые документы, финансовые последствия | `shipment_facts.factType=return`, discrepancy/refusal, claims и finance adjustments покрывают бесплатный контур возврата | Сделано бесплатно, проверено 2026-04-29; отдельный UI возврата позже |
| Возврат ТС после рейса | Машина должна сдать документы, пройти осмотр, топливо/одометр | Послерейсовый чеклист и блокировка следующего рейса при проблемах | Есть API post-trip-return, фиксация одометра/топлива/документов/осмотра, блокировка следующего рейса через cockpit | Сделано, проверено 2026-04-29; нужен UI чеклиста и связка с осмотрами |

## P2. Грузовые ограничения и совместимость

| Сценарий | Продуктовое требование | Почему важно | Работа |
|---|---|---|---|
| Перегруз по массе | Проверка веса груза, массы ТС, прицепа, осевых ограничений | Штрафы, запрет движения, невозможность спецразрешения для делимого тяжеловесного груза | Есть payload capacity check, blocking compatibility, cockpit signal; оси/разрешения фиксируются как следующий бесплатный справочник | Сделано бесплатно, проверено 2026-04-29; платных карт/разрешений нет |
| Объемный груз | Учитывать м3, паллеты, длину/ширину/высоту, способ размещения | Машина может пройти по тоннам, но не пройти по объему/габаритам | Объем/места/паллеты есть в lots/facts, volume compatibility есть, evidence smoke добавлен | Сделано бесплатно, проверено 2026-04-29; 3D-укладка позже |
| Тип кузова | Тент, реф, изотерм, борт, самосвал, цистерна, контейнеровоз | Неверный кузов делает перевозку невозможной или рискованной | Есть compatibility matrix по bodyType/vehicleRequirements + cargo rules для bulk/liquid/ref markers | Сделано бесплатно, проверено 2026-04-29; справочник кузовов можно расширять без платных сервисов |
| Температурный режим | Требования груза, возможности рефа, температурный лог, отклонения | Скоропортящиеся грузы требуют режима и доказательств соблюдения | Есть проверка temperature/ref markers и evidence attachments для ручного температурного листа | Сделано бесплатно, проверено 2026-04-29; датчики/телематика позже |
| Несовместимые грузы | Запрет совместной перевозки определенных категорий | Сборный рейс может быть запрещен по товарному соседству | Сделано, проверено 2026-04-29: cargo rules в compatibility + smoke food vs hazardous/chemical |
| Опасный груз | Класс опасности, ДОПОГ/ADR, допуск водителя/ТС, документы, маршрут | Отдельные требования к перевозке и ответственности | Сделано, проверено 2026-04-29: hazardous/ADR/ДОПОГ markers дают blocking/warning; нужен справочник классов |
| Крупногабарит/тяжеловес | Спецразрешение, маршрут, ограничения дорог, сопровождение | Нужен отдельный permit workflow | Сделано, проверено 2026-04-29: oversized/heavyweight markers и вес >40т проверяются; нужен реальный permit workflow |
| Ценный груз | Объявленная ценность, страхование, пломбы, контроль доступа | Влияет на ответственность, маршрут и документы | Сделано, проверено 2026-04-29: valuable/insurance/seal markers проверяются; нужен UI доказательств |
| Хрупкий груз | Упаковка, крепление, фото до/после, акты повреждений | Доказательная база при претензиях | Damage -> claim, shipment evidence attachments, фото/акт/подпись/GPS smoke покрыты | Сделано бесплатно, проверено 2026-04-29 |
| Наливной/сыпучий груз | Единицы измерения, тара/нетто/брутто, потери, промывка/очистка | Отличается от паллетной логики | Сделано, проверено 2026-04-29: bulk/liquid cargo body compatibility; нужны тара/нетто/промывка |
