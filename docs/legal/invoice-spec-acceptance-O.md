## Что не закрыто и почему

| Пункт | Причина | Backlog |
|---|---|---|
| Backend endpoint `/finance/invoices/:id/print?format=pdf` (server-side PDF) | Используется browser-print через `window.print()` — достаточно для пилота. Серверный PDF (через @react-pdf или Puppeteer) — для batch-экспорта и API-консьюмеров. | Yes |
| Auto-routing по invoice.type | Frontend клиент сам строит URL `/print/{type}/[id]`. UI-кнопка «Печать» в `/finance/invoices/:id` должна это делать. | Yes — `/finance/page.tsx` обновить кнопку печати с typeпереключением |
| Подпись через КЭП (визуальная отметка) | Шаблон содержит футер «может быть подписан КЭП», но визуальная плашка с эл. подписью — отдельная задача (после подключения провайдера КЭП) | Yes |
| Стандартизация footer'а по приказам ФНС | Текущие шаблоны указывают ссылки на нормативку, но не FT-XML формат для электронного обмена через оператора ЭДО | Future (spec §11) |
