### 6.3 Реализовать PDF-выгрузку

**Backend:** `GET /api/legal/[doc].pdf` → конвертация markdown → PDF.

**Frontend:** в LegalPageShell.tsx убрать `disabled` с кнопки PDF, привязать к новому endpoint.

**Зачем:** клиент в момент акцепта должен иметь возможность сохранить **именно ту версию**, на которой он согласился. Это юр-важно для будущих споров: «какая редакция была актуальна на дату акцепта».

**Альтернатива (минимум на MVP):** сохранять SHA-256 hash содержимого markdown в момент акцепта в `terms_acceptances` таблицу (если есть). Тогда можно восстановить версию из git history по hash.

### 6.4 Убрать захардкоженный fallback dateline

В `LegalPageShell.tsx:68`:

```tsx
{dateline ?? 'Действует с 13 мая 2026 года'}
```

Заменить на:

```tsx
{dateline ?? '(дата не указана)'}
```

Или **сделать `dateline` обязательным prop** и убрать fallback. Иначе при следующем обновлении страницы без dateline → клиент увидит **устаревшую дату** как факт.
