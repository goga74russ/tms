### Приказы ФНС России (форматы XML)

**Форматы ЭПД (три ключевых типа документа под обязательную фазу 01.09.2026):**

| Документ | Приказ ФНС | Версия / статус | Обязательность с 01.09.2026 |
|---|---|---|---|
| **ЭТрН** (транспортная накладная) + сопроводительная ведомость + заказ-наряд | **ЕД-7-26/1065@ от 09.12.2021** | действует до 01.09.2026; ФНС внесла **проект о бессрочности** действующих форматов (не новый формат, а снятие срока) | **Да — для всех** участников автоперевозок |
| **ЭЗЗ** (электронный заказ и заявка на перевозку) | **ЕД-7-26/108@ от 13.02.2023** | действует до 01.09.2026; преемник-формат пока не утверждён (проект бессрочности) | **Да — для ВСЕХ грузов.** Отдельный обязательный документ на каждую перевозку; без ЭЗЗ перевозка не считается надлежаще оформленной |
| **ЭПЛ** (электронный путевой лист) | **ЕД-7-26/116@ от 17.02.2023** | действует версия **5.01**; готовится проект **5.02** (не принят) | **Ограниченно — только для маркируемого алкоголя** (пиво, сидр, пуаре, медовуха). Для остальных грузов — добровольно |
| Приказ ФНС № ЕД-7-26/901@ от 21.12.2020 | — | — | Формат УПД (универсальный передаточный документ) |
| ПП РФ № 1137 от 26.12.2011 (ред. с 01.04.2026) | — | — | Форма счёта-фактуры (строка 5б, графа 14 прослеживаемости) |

> ⚠️ **Важно для разработки и питча (сверено вебом 23.06.2026):**
> 1. **Приоритет по обязательности ≠ равный.** Для общего рынка с 01.09.2026 обязательны **ЭТрН + ЭЗЗ** (все грузы). **ЭПЛ обязателен только в алко-нише** — для остального рынка это добровольный документ, а не блокер compliance.
> 2. **ЕД-7-26/383@ от 14.05.2024 — это ЭТрН для ВНУТРЕННЕГО ВОДНОГО транспорта**, не автомобильного. Базовый формат авто-ЭТрН — **1065@**. Если генератор писался по 383@ — он по водному транспорту; для автоперевозок строить по 1065@.
> 3. **Приказов-преемников с НОВЫМ форматом пока нет** — есть проекты о продлении/бессрочности (ЭТрН/ЭЗЗ) и проект ЭПЛ 5.02. Строить можно по действующим приказам, заложив версионирование (особенно ЭПЛ 5.01→5.02). Перед XSD-сертификацией — финальная сверка редакций на nalog.gov.ru.
> 4. Точные XSD-схемы — на nalog.gov.ru и у аккредитованного оператора ЭДО. Версионирование схем в проекте — [../architecture/etrn-source-map.md](../architecture/etrn-source-map.md) (зона TransPult).

## §2 Ключевые факты для проекта

1. **Обязательность с 01.09.2026** — установлена ФЗ-140 от 07.06.2025. До этой даты ЭПД применяются **добровольно** (с 01.01.2022 — возможность, с 01.09.2022 работает ГИС ЭПД).

2. **ГИС ЭПД** — государственная информационная система, оператор — **Минтранс России**, работает с 01.09.2022. Доступ к размещённым документам имеют: Минтранс, МВД, ФНС, Минцифры, Ространснадзор.

3. **Доступ к ГИС ЭПД — только через аккредитованных операторов ЭДО.** Прямого API для конечных пользователей нет (см. [subcontract-legal-analysis.md](subcontract-legal-analysis.md) — почему мы не делаем «прямую интеграцию с ГИС ЭПД»).

4. **ЭТрН = комплект из 8 титулов** (XML), каждый подписывается своим участником своей ЭП. Обязательные для досье: T01 (грузоотправитель), T02 (перевозчик принял), T05 (грузополучатель), T06 (перевозчик закрыл).

5. **Виды подписи в ЭТрН:**
   - КЭП юрлица / КЭП физлица по МЧД — для титулов организации (T01/T02/T05/T06);
   - УНЭП через Госключ — для подписи водителя (T04), приравнена к собственноручной (ст. 6 ч. 2.1 ФЗ-63).

6. **Срок хранения** ЭПД — не менее 5 лет (ст. 9 ФЗ-259 + Перечень типовых управленческих документов).

## §3 Кого касается обязательность (с 01.09.2026)

Все участники автомобильных грузоперевозок, оформляющие перевозочные документы:
- грузоотправители;
- перевозчики;
- грузополучатели;
- экспедиторы.

Бумажное оформление — только по **исключительному перечню Минтранса** (бумажное исключение): техническая недоступность ГИС ЭПД, отдельные категории перевозок и т.п.
