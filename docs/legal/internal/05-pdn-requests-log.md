# Журнал учёта обращений субъектов персональных данных

> **Тип документа:** шаблон журнала + инструкция (внутренний документ оператора).
> **Назначение:** учёт и обработка обращений субъектов ПДн (ст. 18.1 ч. 1 п. 3, ст. 14 ФЗ-152).
> **Утверждается:** приказом № 1-ПДн от 11.06.2026 (Приложение № 4).
> **Ведение:** Ответственный за организацию обработки ПДн.

---

**УТВЕРЖДЁН**
Приказом ИП Бардина Г.Д. от 11.06.2026 № 1-ПДн (Приложение № 4)

## ЖУРНАЛ учёта обращений субъектов персональных данных

## 1. Назначение и порядок ведения

1.1. Журнал ведётся для учёта обращений субъектов ПДн (или их представителей) по вопросам обработки их персональных данных и контроля сроков ответа.

1.2. Виды обращений:
- запрос информации об обработке ПДн (ст. 14 ч. 1 ФЗ-152);
- требование уточнения, блокирования, уничтожения ПДн (ст. 14 ч. 1, ст. 21);
- отзыв согласия на обработку (ст. 9 ч. 2);
- требование переноса данных в машиночитаемом формате (ст. 14.1 ч. 3);
- жалоба на действия Оператора.

1.3. Каналы приёма обращений:
- email: privacy@transpult.ru;
- письменное заявление по адресу регистрации Оператора;
- через интерфейс Сервиса (личный кабинет).

## 2. Сроки ответа

| Вид обращения | Срок |
|---|---|
| Предоставление информации об обработке ПДн | **10 рабочих дней** с возможностью продления ещё на 5 рабочих дней (ст. 14 ч. 2 ФЗ-152) |
| Уточнение / блокирование / уничтожение по подтверждённому требованию | **7 рабочих дней** (ст. 21 ч. 3) |
| Отзыв согласия — прекращение обработки | **30 календарных дней** (ст. 21 ч. 5) |
| Перенос данных | в разумный срок, ориентир — 30 календарных дней |
| Жалоба | 30 календарных дней |

## 3. Форма журнала

| № п/п | Дата обращения | ФИО субъекта (или представителя) | Канал | Вид обращения | Содержание (кратко) | Срок ответа (до) | Дата ответа | Результат / принятые меры | Ответственный |
|---|---|---|---|---|---|---|---|---|---|
| 1 | | | | | | | | | |
| 2 | | | | | | | | | |

## 4. Порядок обработки обращения

4.1. **Регистрация.** Обращение регистрируется в Журнале в день поступления (или следующий рабочий день).

4.2. **Идентификация.** Ответственный удостоверяется, что обращение исходит от субъекта ПДн или его уполномоченного представителя (во избежание раскрытия ПДн третьим лицам). При сомнениях — запрашивается подтверждение личности.

4.3. **Рассмотрение по существу.** Ответственный определяет:
- какие ПДн субъекта обрабатываются;
- на каком основании;
- возможно ли удовлетворить требование (с учётом обязательных сроков хранения — см. Регламент уничтожения, Приложение № 3).

4.4. **Ответ.** Направляется субъекту тем же каналом (или указанным в обращении) в установленный срок. При отказе — с мотивированным обоснованием (например, «ПДн не могут быть уничтожены до истечения срока хранения по ФЗ-259»).

4.5. **Фиксация.** Результат и принятые меры заносятся в Журнал.

## 5. Особые случаи

5.1. **Обращение по ПДн, обрабатываемым по поручению клиента-оператора** (большинство ПДн водителей/контрагентов): Оператор как обработчик **перенаправляет** обращение оператору-клиенту (работодателю субъекта) либо обрабатывает совместно — в соответствии с условиями DPA «Клиент ↔ TMS». Субъект уведомляется о том, кто является оператором его данных.

5.2. **Отзыв согласия водителем на Госключ / КЭП:** обрабатывается с учётом того, что уже подписанные документы сохраняют юр-силу и не уничтожаются (см. согласия в юр-пакете ЭТрН).

## 6. Хранение журнала

Журнал и копии обращений/ответов хранятся **не менее 5 лет** с даты обращения.

## Комментарии для применения (не печатать)

1. **Форма ведения** — электронная (таблица/БД) либо бумажная. Для Сервиса оптимально — отдельная таблица в админ-панели с экспортом. Это ТЗ для TransPult (не блокер пилота): функционал «Обращения субъектов ПДн» в `/admin`.
2. **Идентификация (п. 4.2)** — критична. Нельзя выдавать информацию об обработке ПДн лицу, не подтвердившему, что он субъект. Иначе сам факт ответа = утечка.
3. **Разграничение оператор/обработчик (п. 5.1)** — ключевой нюанс. По большинству ПДн (водители, контрагенты) Оператор TMS — обработчик, а оператор — клиент-перевозчик. Обращения по таким данным маршрутизируются клиенту. По ПДн собственных пользователей Сервиса (учётные записи) — Оператор TMS отвечает сам.
4. **При регистрации ООО** — переутвердить, сменить ответственного.
