# Инструкция диспетчера

> **Кто вы:** диспетчер превращает заявку логиста в выполненный рейс — назначает транспорт, формирует путевой лист, следит за выпуском и ходом перевозки.
>
> **Где вы работаете:** **Диспетчерская** (`/dispatcher`) — оперативный центр с картой, и **Рейсы** (`/trips`) — реестр и досье рейсов.

---

## Вход и навигация

После входа вы попадёте в **Диспетчерскую** (`/dispatcher`). При первом входе показывается обучающий тур из 5 шагов — пройдите его кнопкой **«Далее»** или закройте **«Пропустить»**.

В левом меню диспетчеру доступны:

| Пункт | Куда ведёт | Зачем |
|---|---|---|
| Главная | `/` | Стартовая страница |
| Заявки | `/orders` | Все заявки таблицей |
| Диспетчерская | `/dispatcher` | Карта + назначение рейсов |
| Рейсы | `/trips` | Реестр рейсов, досье, путевые листы |
| Путевые листы | `/waybills` | ПЛ по рейсам |
| Автопарк | `/fleet` | ТС, статусы, документы |
| Водители | `/drivers` | Реестр водителей |
| Инциденты | `/incidents` | Происшествия по рейсам |
| Претензии | `/claims` | Претензии |

## Диспетчерская (`/dispatcher`) — оперативный центр

Экран состоит из нескольких зон:

- **Карта** (OpenStreetMap) — позиции ТС, маршруты. Переключатели вида и кнопка **«Обновить»** для актуализации данных. Кнопки `+` / `−` — масштаб.
- **Статус операций** (вверху) — счётчики: **Блокеры**, **Риски**, **OK / инфо**. Это операционные события по рейсам (нарушение режима отдыха экипажа, возврат ТС, простой на точке, изменение маршрута, ЭТрН-блокеры). Клик по счётчику фильтрует список событий.
- **Live рейсы** — список рейсов в работе с их статусом (В пути, Выпущен и т.д.).
- **Транспорт** — список ТС со статусом: **Свободен** / **Назначен** / **В рейсе** / **Неисправен**. Фильтры: Все / Своб. / Назнач. / В рейсе / Неиспр.
- **Назначение** — правая панель, где собственно назначается рейс (см. ниже).

> Карта подгружается тяжело — если правая панель «Назначение» не видна сразу, дайте странице секунду или нажмите «Обновить».

## Сценарий 1. Назначить рейс (заявка → ТС)

Назначение делается в панели **«Назначение»**:

1. **Поиск ТС.** В поле «Госномер, марка, модель…» начните вводить — система покажет **только свободные** ТС. Выберите нужный из выпадающего списка.
   - Появится зелёная карточка выбранного ТС: госномер, марка/модель, грузоподъёмность и **закреплённый за ним водитель** (отдельно водителя выбирать не нужно — он привязан к машине).
2. **Фильтр по городу** (опционально). Введите город — список заявок ниже отфильтруется по адресам погрузки/выгрузки.
3. **Окна доставки** (опционально). 4 поля даты-времени: погрузка с/до, выгрузка с/до. Можно оставить пустыми.
4. **Заявки.** В списке внизу панели кликните на нужную заявку — она подсветится. Повторный клик снимает выбор.
5. Нажмите **«Назначить»**.

**Когда кнопка «Назначить» неактивна** — наведите на неё курсор, подсказка скажет чего не хватает: «Выберите заказ», «Выберите автомобиль» или оба.

### Подсказки и проверки при назначении

- **Перевес по весу.** Если груз тяжелее грузоподъёмности ТС — система покажет красное уведомление «Перевес!» и не даст назначить.
- **Загрузка по объёму** (кубы). Над списком появляется индикатор «Загрузка по объёму: X / Y м³ (Z%)». При перегрузе по объёму назначение блокируется.
- **ADR (опасный груз).** Если заявка помечена классом ADR — рядом с номером жёлтый бейдж `ADR-N`, а в панели появляются предупреждения о совместимости. Они **не блокируют** назначение, но проверьте перед подтверждением.

После назначения: ТС переходит в статус **Назначен**, создаётся рейс с номером `TRP-2026-XXXXX`, заявка уходит в статус «Назначена».

## Сценарий 2. Сформировать путевой лист и выпустить рейс

Дальнейшая работа — в разделе **Рейсы** (`/trips`).

1. Найдите свой рейс в реестре (фильтры по статусу сверху: Все / Планирование / Назначен / ПЛ черновик / Осмотр / ПЛ выдан / Погрузка / В пути / Завершён / Оплачен / Отменён).
2. Нажмите **«Досье»** в строке рейса — откроется карточка рейса.
3. В досье виден блок **«Готовность к выпуску»** — чек-лист `N/6`:
   - тип ТС для ПЛ,
   - водитель привязан,
   - технический и медицинский осмотры пройдены,
   - ПЛ оформлен,
   - досье доступно,
   - заявки в рейсе.
4. Нажмите **«Сформировать ПЛ»** — создаётся путевой лист (`WB-2026-XXXXX`). Готовность станет `6/6`, статус рейса сменится на **«ПЛ выдан»**.

> **Готовность не доходит до 6/6** — значит не пройдены осмотры. Техосмотр делает механик (`/mechanic`), медосмотр — медик (`/medic`). Пока ТС и водитель не допущены, ПЛ выпустить нельзя.

---

## Сценарий 3. Контроль хода рейса

- **Старт рейса и движение** выполняет **водитель в мобильном приложении** (принять рейс, отметить погрузку, прибытие, выгрузку). Через web диспетчер старт не запускает.
- Статус рейса в реестре `/trips` обновляется автоматически: ПЛ выдан → Погрузка → В пути → Завершён.
- На карте в Диспетчерской видно позицию ТС и отклонения.
- **Блокеры и риски** по рейсу собираются в «Статусе операций» Диспетчерской.

### Принудительное завершение

Если рейс нужно закрыть без подтверждения водителя (например, водитель недоступен) — в досье/диспетчерской есть действие **«Принудительное завершение»**. Потребуется указать причину. Используйте только в исключительных случаях.

## Документы рейса

В досье рейса и на странице **Документы рейса** (`/trips/<id>/documents`) доступны:

- путевой лист (ПЛ),
- ТТН / транспортная накладная,
- ЭТрН (электронная транспортная накладная) — со статусами выпуска и подписания,
- акты.

Статусы документов: черновик → отправлен → принят/подписан, либо отклонён/ошибка (подсвечиваются красным).

## Частые вопросы

**В поиске ТС пусто / «Нет свободных ТС».** Все подходящие ТС заняты на других рейсах или неисправны. Проверьте список «Транспорт» — статусы машин. Освободится ТС — появится в поиске.

**Не могу назначить — кнопка серая.** Наведите курсор на «Назначить» — подсказка скажет, что не выбрано (ТС или заявка). Нужно выбрать и то и другое.

**Назначил, но не могу выпустить ПЛ — готовность не 6/6.** Не пройдены осмотры. Передайте ТС механику на техосмотр, водителя — медику на медосмотр.

**Где стартовать рейс?** Старт — в мобильном приложении водителя, не в web. Диспетчер только формирует ПЛ и наблюдает.
