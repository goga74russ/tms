# Инструкция бухгалтера

> **Кто вы:** бухгалтер выставляет счета за выполненные рейсы, ведёт реестр счетов, работает с тарифами и выгрузкой в 1С.
>
> **Где вы работаете:** раздел **Финансы** (`/finance`).

---

## Вход и навигация

После входа вы попадёте в **Финансы** (`/finance`).

В левом меню бухгалтеру доступны:

| Пункт | Куда ведёт | Зачем |
|---|---|---|
| Главная | `/` | Стартовая страница |
| Заявки | `/orders` | Заявки таблицей (для сверки) |
| Контрагенты | `/contractors` | Клиенты, реквизиты |
| Финансы | `/finance` | Счета, реестр, выставление — основной экран |
| СФ с просрочкой | `/finance/sf-overdue` | Счета-фактуры с просрочкой |
| Тарифы | `/tariffs` | Тарифы по договорам |
| Аналитика | `/analytics` | Финансовая аналитика |
| Претензии | `/claims` | Претензии |

---

## Главный экран — Финансы

Вверху — переключатель периода: **Неделя / 4 недели / Месяц / Квартал / Год / Всё / Свой период**. Все цифры на экране считаются за выбранный период.

Плитки-метрики:

- **К оплате** — сумма и число выставленных, но не оплаченных счетов.
- **Просрочено (дебиторка)** — задолженность с истёкшим сроком.
- **Оплачено** — за период.
- **Всего счетов** — за период.

Ниже — **Реестр счетов** с фильтром по статусу: **Черновик / Отправлен / Оплачен / Просрочен / Отменён**. По каждому счёту: номер (`СЧ-2026-XXXXX`), тип, период, сумма, НДС, итого, статус и меню действий (`⋮`).

Кнопки сверху: **«Счёт по рейсам»**, **«Пакетом»**, **«Экспорт 1С (XML)»**.

---

## Сценарий 1. Выставить счёт по рейсам

1. (Опционально) Выберите контрагента в выпадающем списке и период — реестр отфильтруется.
2. Нажмите **«Счёт по рейсам»** — откроется форма создания:
   - выбор контрагента;
   - период (поля даты «с» / «по»);
   - список рейсов с чекбоксами — отметьте те, что войдут в счёт (можно несколько — счёт будет сводным);
   - переключатели/опции расчёта.
3. Проверьте состав и сумму (тариф × объём/расстояние, НДС).
4. Нажмите **«Сформировать»**.

Счёт появится в реестре со статусом **«Черновик»**. Дальше его можно отправить контрагенту (в т.ч. через ЭДО) и отслеживать статус оплаты.

> Счёт по рейсу можно выставить после того, как рейс **завершён**. Незавершённые рейсы в форму не попадут.

---

## Сценарий 2. Пакетное выставление

Кнопка **«Пакетом»** — массовое формирование счетов сразу по нескольким контрагентам/рейсам за период. Используйте при закрытии месяца, когда нужно выставить много счетов разом.

---

## Сценарий 3. Управление счётом

В реестре у каждого счёта меню действий (`⋮`):

- отправить контрагенту (включая ЭДО, если подключён оператор);
- скачать PDF / печатную форму;
- отметить оплату;
- отменить / скорректировать.

Статусы счёта: **Черновик** → **Отправлен** → **Оплачен** (либо **Просрочен** / **Отменён**).

---

## Сценарий 4. Выгрузка в 1С

Кнопка **«Экспорт 1С (XML)»** выгружает счета за выбранный период в формате для загрузки в 1С. Подробнее о настройке обмена — см. [интеграции](integrations-setup.md).

---

## Важно: налоговый режим организации

Выпуск счетов и счетов-фактур **заблокирован**, пока администратор не выбрал налоговый режим организации (ОСНО / УСН / АУСН / Патент / НПД) — от него зависит логика НДС. Если выставление недоступно — попросите администратора заполнить налоговый режим в админ-панели.

---

## Частые вопросы

**Нужного рейса нет в форме «Счёт по рейсам».** Скорее всего рейс ещё не завершён. Счёт выставляется по завершённым рейсам. Уточните статус у диспетчера.

**Не могу выставить счёт — функция заблокирована.** Не выбран налоговый режим организации. Это делает администратор в админ-панели (см. выше).

**Где раздел «Биллинг»?** Вся работа со счетами теперь в разделе **Финансы** (`/finance`). Отдельной страницы «Биллинг → Готовые к выставлению» в текущей версии нет — используйте «Счёт по рейсам» / «Пакетом».

**Цифры в метриках = 0, хотя счета есть.** Проверьте выбранный период вверху — метрики считаются только за него. Переключите на «Всё», чтобы увидеть полную картину.
