# Инструкция бухгалтера

Бухгалтер работает в разделе **Финансы** (`/finance`) и отвечает за:

- выставление счетов и формирование актов;
- обмен документами через ЭДО;
- выгрузку данных в 1С;
- сверку расчётов с контрагентами.

## Главный экран

В дашборде показано:

- счета к выставлению (за закрытые, но ещё не оплаченные рейсы);
- ожидающие оплаты (выставленные, но не оплаченные);
- просроченная задолженность (по контрагентам);
- доход за месяц / квартал.

## Формирование счёта

1. Перейдите в **Биллинг → Готовые к выставлению**.
2. Выберите рейсы (можно сразу несколько — счёт формируется сводным).
3. Проверьте расчёт: тариф × объём, доп. услуги, НДС.
4. Нажмите **«Сформировать счёт»**.
5. Скачайте PDF или отправьте через ЭДО.

Шаблон счёта подтягивает реквизиты организации из раздела **Настройки**.

## Акты выполненных работ

После закрытия рейса акт формируется автоматически на основе путевого
листа и тарифа. Вручную можно:

- объединить несколько рейсов в один акт за период;
- скорректировать суммы (с обоснованием);
- добавить доп. строки (простой, доп. услуги).

## ЭДО

Если подключён один из операторов (Контур.Диадок, СБИС, Калуга Астрал,
Такском) — счёт, акт и ЭТрН отправляются прямо в кабинет контрагента.

Состояния:

- **Отправлен** — документ ушёл, ждём подписи.
- **Подписан** — обе стороны подписали.
- **Отклонён** — контрагент отклонил, причина в комментарии.

См. [настройка ЭДО](integrations-setup.md).

## Выгрузка в 1С

В разделе **Интеграции → 1С**:

- настройте обмен (XML / JSON по выбору);
- укажите периодичность (вручную / ежедневно / ежемесячно);
- выберите справочники (контрагенты, ТС, договоры);
- выберите документы (счета, акты, накладные).

Поддерживаются конфигурации:

- 1С:Бухгалтерия предприятия 3.0;
- 1С:Управление торговлей 11;
- 1С:ERP.

## Сверка расчётов

В разделе **Финансы → Контрагенты** для каждого партнёра доступен:

- акт сверки по периоду (с возможностью отправки контрагенту);
- история выставленных и оплаченных счетов;
- задолженность с разбивкой по срокам (0–30, 30–60, 60–90, > 90 дней).

## Закрытие месяца

Чек-лист на конец месяца:

1. Все рейсы за месяц закрыты в диспетчере.
2. По всем закрытым рейсам сформированы акты.
3. Акты отправлены контрагентам через ЭДО или почту.
4. Выгрузка в 1С выполнена.
5. Сверка расчётов с топ-10 контрагентами.

Если что-то осталось — на дашборде это подсвечивается.
