# Подключение интеграций

Все интеграции включаются из раздела **Настройки → Интеграции**.
В бесплатном режиме доступны mock-провайдеры — система работает,
но без реального обмена данными.

## ЭДО (электронный документооборот)

Поддерживаются операторы:

| Оператор | Что нужно для подключения |
|----------|---------------------------|
| Контур.Диадок | Логин/пароль или API-ключ кабинета |
| СБИС | Лицензия + сертификат КЭП |
| Калуга Астрал | Договор + ID кабинета |
| Такском | Логин/пароль + сертификат |

Шаги:

1. Получите доступ у оператора (если ещё нет).
2. Откройте **Настройки → Интеграции → ЭДО**.
3. Выберите оператора.
4. Введите учётные данные / загрузите сертификат.
5. Нажмите **«Проверить связь»** — система отправит тестовый запрос.
6. Сохраните.

Активный оператор показан на главной странице бухгалтера.

> **Переключение оператора** не требует переоформления документов:
> новые документы пойдут через нового оператора, история сохранится.

## Wialon (GPS-трекинг)

Доступно на тарифе Business и выше.

1. Получите от Wialon хост, логин и пароль (или OAuth-токен).
2. **Настройки → Интеграции → GPS → Wialon**.
3. Введите параметры подключения.
4. Сопоставьте объекты Wialon с вашими ТС в TMS (по госномеру или вручную).
5. Нажмите **«Синхронизировать»**.

После настройки координаты, скорость и одометр обновляются автоматически
каждые 60 секунд.

## Электронная подпись

### Госключ (бесплатно для ИП и физлиц)

1. Установите приложение Госключ на телефон.
2. В TMS откройте **Настройки → Подпись → Госключ**.
3. Нажмите **«Привязать»** — приложение откроет QR-код.
4. Подтвердите в Госключе.

### КриптоПро CSP (для ООО, КЭП на токене)

1. Установите КриптоПро CSP на компьютер.
2. Подключите токен (Рутокен / JaCarta).
3. В TMS откройте **Настройки → Подпись → КриптоПро**.
4. Браузер запросит выбор сертификата — выберите КЭП организации.
5. Сохраните.

> Для подписи через браузер нужно установить плагин «КриптоПро ЭЦП Browser
> plug-in» (бесплатный).

## Платежи (ЮKassa / Тинькофф / CloudPayments)

1. Получите учётные данные у платёжного агрегатора (магазин, ключ).
2. **Настройки → Интеграции → Платежи**.
3. Выберите провайдера, введите ключи.
4. Настройте webhook URL (TMS покажет нужный адрес).
5. Сохраните.

После этого ваши клиенты смогут оплачивать счета по ссылке из e-mail.

## DaData (подсказки реквизитов)

Опционально — ускоряет ввод данных контрагентов и адресов.

1. Получите API-ключ на dadata.ru.
2. **Настройки → Интеграции → DaData**.
3. Введите ключ.
4. Сохраните.

## Тахограф (DDD-файлы)

Для коммерческих ТС ≥ 3,5 т.

1. Считайте файл с тахографа стандартными средствами.
2. **Парк → ТС → DDD-файлы → Загрузить**.
3. Система разберёт смены, режим труда и отдыха.

## Маркировка «Честный знак»

Если перевозите маркируемый товар:

1. **Настройки → Интеграции → Честный знак**.
2. Введите учётные данные кабинета участника.
3. Подключите КЭП.
4. Сохраните.

## Что в бесплатном режиме

Все интеграции имеют **mock-провайдеры**, которые имитируют поведение без
реального внешнего сервиса. Это позволяет:

- пройти онбординг и тесты;
- увидеть, как выглядит подписанный ЭТрН в интерфейсе;
- развернуть on-premise-демо.

Для production-использования нужен реальный провайдер.
