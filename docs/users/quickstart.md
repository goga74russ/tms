# Быстрый старт за 10 минут

Этот гайд показывает, как зарегистрироваться, провести первого водителя
по полному циклу и получить первый счёт.

## 1. Регистрация (1 минута)

1. Откройте `https://app.tms-prod.ru/landing`.
2. Нажмите **«Начать бесплатно»**.
3. Введите e-mail, пароль, ИНН организации.
4. Подтвердите e-mail по ссылке из почты.

![Заглушка](placeholder.png)

## 2. Онбординг — мастер из 6 шагов (5 минут)

После входа автоматически открывается мастер. Заполните:

1. **Организация** — название, ИНН, реквизиты.
2. **Сотрудники** — добавьте логиста, диспетчера, бухгалтера.
3. **Транспорт** — 1–2 машины (марка, госномер, VIN).
4. **Водители** — ФИО, телефон, водительское удостоверение.
5. **Контрагенты** — 1–2 заказчика (можно загрузить через Excel).
6. **Тарифы** — базовый тариф «руб/км» или «руб/час».

Все шаги можно пропустить и заполнить позже из соответствующих разделов.

![Заглушка](placeholder.png)

## 3. Создание заказа (1 минута)

1. Перейдите в раздел **Логистика → Заявки**.
2. Нажмите **«Новая заявка»**.
3. Укажите: контрагента, точки погрузки/выгрузки, груз, дату.
4. Сохраните.

## 4. Назначение рейса (1 минута)

1. Перейдите в раздел **Диспетчер → Рейсы**.
2. Выберите созданную заявку.
3. Назначьте водителя и ТС.
4. Нажмите **«Сформировать путевой лист»**.

## 5. Прохождение осмотров (1 минута)

В мобильном приложении водителя:

1. Водитель открывает рейс.
2. Проходит предрейсовый медосмотр (если медик настроен — у медика).
3. Проходит технический осмотр.
4. Получает разрешение на выезд.

![Заглушка](placeholder.png)

## 6. Доставка (1 минута)

Водитель отмечает чекпоинты в приложении: погрузка, выгрузка,
фотофиксация документов. Диспетчер видит статус в реальном времени.

## 7. Биллинг и счёт (1 минута)

После закрытия рейса:

1. Перейдите в **Финансы → Биллинг**.
2. Нажмите **«Сформировать счёт»** для рейса.
3. Скачайте PDF или отправьте через ЭДО (если подключён).

Готово. Вы прошли полный цикл `order → trip → waybill → inspections →
delivery → invoice`.
