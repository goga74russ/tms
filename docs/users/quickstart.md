# Быстрый старт за 10 минут

Этот гайд показывает, как зарегистрироваться, провести первого водителя
по полному циклу и получить первый счёт.

## 1. Регистрация (1 минута)

1. Откройте `https://<ваш-домен>/landing`.
2. Нажмите **«Начать бесплатно»**.
3. Введите e-mail, пароль, ИНН организации.
4. Подтвердите e-mail по ссылке из почты.


## 2. Онбординг — мастер из 6 шагов (5 минут)

После входа автоматически открывается мастер. Шаги:

1. **ИНН** — DaData подтянет название/КПП/ОГРН/адрес.
2. **Реквизиты** — подтвердите данные компании.
3. **Сценарий** — выберите тип бизнеса (преднастройка модулей).
4. **Оператор ЭДО** — Диадок / СБИС / Калуга Астрал / Такском.
5. **Электронная подпись** (опционально) — Госключ или КЭП.
6. **Команда** (опционально) — пригласите коллег по e-mail.

Транспорт, водители, контрагенты и тарифы заводятся после онбординга
из соответствующих разделов. Все шаги можно пропустить.


## 3. Создание заявки — логист (1 минута)

1. Войдите как логист → откроется **Канбан логиста** (`/logist`).
2. Нажмите **«Новая заявка»**.
3. Вкладка **«Основное»**: контрагент, груз, вес, адреса и даты погрузки/выгрузки. (Спец-требования — температура, ADR, цена — на вкладке **«Расширенное»**.)
4. **«Создать заявку»** → заявка в колонке **Черновик**.
5. Нажмите **«В работу»** на карточке — теперь её видит диспетчер.

## 4. Назначение рейса — диспетчер (1 минута)

1. Войдите как диспетчер → **Диспетчерская** (`/dispatcher`).
2. В панели **«Назначение»**: найдите свободный ТС (водитель привязан к ТС), выберите заявку из списка.
3. Нажмите **«Назначить»** → создаётся рейс `TRP-2026-XXXXX`.

## 5. Осмотры — механик и медик (1 минута)

1. **Механик** (`/mechanic`): открыть ТС → чек-лист → «Допустить» → пароль ПЭП.
2. **Медик** (`/medic`): открыть водителя → показатели → «Допустить» → пароль ПЭП.

## 6. Выпуск ПЛ — диспетчер (1 минута)

1. Диспетчер → **Рейсы** (`/trips`) → «Досье» рейса.
2. Готовность должна быть **6/6** → **«Сформировать ПЛ»** → статус «ПЛ выдан».

## 7. Выполнение рейса — водитель (мобильное приложение)

Старт, погрузка, выгрузка и завершение рейса водитель отмечает **в мобильном приложении** (через веб эти действия недоступны). Диспетчер видит статус в реальном времени.

## 8. Счёт — бухгалтер (1 минута)

После **завершения** рейса:

1. Бухгалтер → **Финансы** (`/finance`).
2. **«Счёт по рейсам»** → выбрать контрагента, период, отметить рейсы → **«Сформировать»**.
3. Отправьте контрагенту (в т.ч. через ЭДО) или выгрузите в 1С.

> Выпуск счетов заблокирован, пока администратор не выбрал **налоговый режим** организации (ОСНО/УСН/АУСН/Патент/НПД).

Готово. Вы прошли полный цикл `заявка → рейс → осмотры → ПЛ → доставка → счёт`.
