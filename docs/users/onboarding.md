# Онбординг — мастер из 6 шагов

Цель онбординга — за 5–10 минут собрать минимально достаточные данные
для запуска первой перевозки. Каждый шаг можно пропустить и заполнить
позже из соответствующего раздела.

> См. реальный wizard в `apps/web/src/app/onboarding/page.tsx`.

## Шаг 1. ИНН компании

Введите ИНН (10 цифр — для юрлица, 12 — для ИП/физлица). По нему через
DaData автоматически подтянутся название, КПП, ОГРН и юридический адрес
из госреестра. Если данные не нашлись, шаг можно пройти вручную на
следующем экране.

## Шаг 2. Реквизиты компании

Подтвердите и при необходимости отредактируйте подтянутые данные:

- **Полное наименование** (как в ЕГРЮЛ/ЕГРИП).
- **Краткое наименование** (используется в UI).
- **ИНН / КПП** — для физлиц только ИНН.
- **ОГРН / ОГРНИП**.
- **Юридический адрес**.

Реквизиты используются всеми документами; ошибка здесь приведёт к
ошибкам в счетах и накладных. Перепроверяйте перед сохранением.

## Шаг 3. Сценарий

Выберите тип своего бизнеса — TMS преднастроит модули и интеграции
под типовой сценарий («Малый перевозчик», «Средняя компания с ЭДО»,
«Холодовая цепь», и т.п.). Изменить сценарий можно позже в настройках.

## Шаг 4. Оператор ЭДО

Выберите оператора электронного документооборота (Контур.Диадок, СБИС,
Калуга Астрал, Такском). Подключение реальных ключей делается позже в
разделе **Админ → Интеграции** — на этом шаге фиксируется выбор.

## Шаг 5. Электронная подпись (опционально)

Способ подписания документов: **Госключ** (бесплатно, для ИП и физлиц,
через приложение Госуслуги) или **КЭП** (КриптоПро / Контур.Подпись /
СБИС). Без ЭП работать можно, но подписание документов будет недоступно.

## Шаг 6. Команда (опционально)

Пригласите коллег по e-mail. Минимально полезные роли:

- **Логист** — принимает заявки, ведёт контрагентов и тарифы.
- **Диспетчер** — формирует рейсы и путевые листы.
- **Бухгалтер** — выставляет счёта, ведёт ЭДО.

Если работаете один — пропустите шаг и пригласите команду позже из
**Админ → Пользователи**.

## После онбординга

После прохождения мастера откроется главная страница вашей роли:

- Логист → `/logist`
- Диспетчер → `/dispatcher`
- Бухгалтер → `/finance`
- Руководитель → `/kpi`

Сразу после онбординга можно добавить транспорт, водителей, контрагентов
и тарифы — из соответствующих разделов либо bulk-импортом из Excel.
