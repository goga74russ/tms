# Онбординг — мастер из 6 шагов

Цель онбординга — за 5–10 минут собрать минимально достаточные данные
для запуска первой перевозки. Каждый шаг можно пропустить и заполнить
позже из соответствующего раздела.

## Шаг 1. Организация

Здесь фиксируются реквизиты, которые попадут в путевые листы, ЭТрН и счета.

- **Полное наименование** (как в ЕГРЮЛ/ЕГРИП).
- **Краткое наименование** (используется в UI).
- **ИНН / КПП** — для физлиц только ИНН.
- **ОГРН / ОГРНИП**.
- **Юридический адрес**, фактический адрес, почтовый.
- **Расчётный счёт** — банк, БИК, корсчёт.
- **Подписант** — ФИО, должность, основание (Устав / доверенность).

> Реквизиты используются всеми документами; ошибка здесь приведёт к
> ошибкам в счетах и накладных. Перепроверяйте перед сохранением.

## Шаг 2. Сотрудники

Заведите учётные записи для ключевых ролей. Минимально нужны:

- **Логист** — принимает заявки, ведёт контрагентов и тарифы.
- **Диспетчер** — формирует рейсы и путевые листы.
- **Бухгалтер** — выставляет счёта, ведёт ЭДО.

Опциональные роли: руководитель (KPI), механик, медик.

Каждому сотруднику отправляется приглашение на e-mail. Пользователь
устанавливает свой пароль при первом входе.

## Шаг 3. Транспорт

Заведите парк ТС. Для каждой машины укажите:

- марка и модель;
- год выпуска;
- VIN (17 символов);
- госномер;
- категорию (легковой / грузовой / седельный тягач);
- грузоподъёмность, объём кузова;
- температурный режим (для рефрижераторов);
- ОСАГО (даты действия) — необязательно на старте.

Можно загрузить файлом через **Парк → Импорт XLSX**.

## Шаг 4. Водители

Каждому водителю заводится карточка с:

- ФИО, дата рождения;
- телефон (используется для входа в мобильное приложение);
- водительское удостоверение (категория, серия, дата выдачи, дата окончания);
- медицинская справка;
- допуск к опасным грузам (если применимо).

Поля **«серия паспорта»** и **«номер паспорта»** обязательны для
оформления путевых листов.

## Шаг 5. Контрагенты

Заведите ключевых заказчиков и поставщиков. Для каждого:

- наименование;
- ИНН;
- адрес;
- контактное лицо;
- e-mail для документов и для ЭДО.

Импорт из Excel/CSV доступен по кнопке **«Импорт»**.

## Шаг 6. Тарифы

Базовый тариф нужен для расчёта стоимости перевозок:

- тип: за км / за час / фикс / за тонну;
- ставка;
- НДС-режим (с НДС / без);
- валюта (по умолчанию RUB);
- условия применения (контрагент, маршрут, период).

Можно добавлять расширенные тарифы позже из раздела **Тарифы**.

## После онбординга

После прохождения мастера откроется главная страница вашей роли:

- Логист → `/logist`
- Диспетчер → `/dispatcher`
- Бухгалтер → `/finance`
- Руководитель → `/kpi`
