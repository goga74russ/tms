# QA: ручная проверка ЭПД XSD-сертификации (ветка `feat/epd-xsd-validator`)

**Что проверяем:** генераторы 14 документов ФНС (ЭТрН ×6 титулов, ЭЗЗ ×2, ЭПЛ ×6)
формируют XML, проходящий РЕАЛЬНУЮ XSD-схему ФНС. Цель QA — независимо убедиться,
что (а) автотесты зелёные, (б) наш XML валиден по официальной схеме, (в) эндпоинты
отдают XML или честный 422 (без фиктивных данных).

Автор уже прогнал: `tsc --noEmit` (чисто), 24 теста (зелёные), harness (все valid).
Ниже — чтобы QA подтвердил руками.

## Уровень 2 — НЕЗАВИСИМАЯ проверка официальным xmllint (libxml2)

Это ключевой шаг «руками»: валидируем наш XML НЕ нашим кодом, а официальной
утилитой libxml2 против схемы ФНС.

### 2.1 Выгрузить образцы
```bash
cd apps/api && npx tsx scripts/epd-emit-samples.ts qa-epd-samples
```
Создаст `apps/api/qa-epd-samples/` — 14 файлов `*.xml` (UTF-8) + папку `schemas/`
с UTF-8-копиями нужных XSD. В конце скрипт печатает готовые команды `xmllint`.

### 2.2 Поставить xmllint (если нет)
- Windows: `choco install xsltproc` (включает xmllint) либо из MSYS2/Git-for-Windows;
  проверка: `xmllint --version`.
- Linux/Mac: `apt install libxml2-utils` / `brew install libxml2`.

### 2.3 Прогнать (команды печатает скрипт из 2.1)
```bash
cd apps/api
xmllint --noout --schema qa-epd-samples/schemas/ON_TRNACLGROT_1_973_01_05_01_02.xsd qa-epd-samples/etrn-t01.xml
# ... и так для всех 14 (полный список — в выводе скрипта)
```
**Ожидаемо для каждого:** `<файл>.xml validates`.

> Альтернатива без установки xmllint: открыть любой XML из `qa-epd-samples/` и
> прогнать через онлайн-валидатор XSD (загрузив рядом лежащую схему из `schemas/`),
> либо через тестовый валидатор оператора ЭДО (Диадок/СБИС/Контур).

## Известные ЧЕСТНЫЕ 422 (это НЕ баги)

Дисциплина проекта: не подставляем фиктивные реквизиты. Если обязательного по XSD
поля нет в TMS — эндпоинт отдаёт `422` с указанием поля (`code: ETRN_DATA_INCOMPLETE`,
`field: …`). Ожидаемые случаи:

- **`/orders/:id/ezz`** — 422 на габаритах грузового места (`РазмерГрМест`) и
  требуемых параметрах ТС: TMS их пока не хранит.
- **`/waybills/:id/epl`** — 422 если у организации-перевозчика не заполнен ОГРН
  (`organizations.ogrn`).
- **`/waybills/:id/etrn`** — 422 если нет телефона водителя (берётся из `users.phone`
  через `drivers.userId`), мест груза или номера заказа.
- Также 422 на отсутствии ИНН грузоотправителя/перевозчика/грузополучателя.

Это корректное поведение: лучше честный отказ, чем невалидный/выдуманный документ.

### Баг BUG-EPD-01 (Level 2): СвПер без Контакт в ЭТрН T01

- **Файл:** `apps/api/src/modules/waybills/etrn-generator.ts:229`
- **Severity:** P2 (XSD-невалидность при `carrierPhone` = undefined)
- **Что не так:** `renderContact(undefined, address)` → fallback `<Адрес>` вместо `<Контакт>`. Но `УчастникТрНТип` в XSD `ON_TRNACLGROT_1_973_01_05_01_02.xsd:2907` объявляет `<Контакт>` **без** `minOccurs="0"` → обязателен. `<Адрес>` — `minOccurs="0"` → опционален. Комментарий в коде («требует один из `<Адрес>`/`<Контакт>`») ошибочен.
- **Воспроизведение:** вызвать `generateETrN({..., carrierPhone: undefined})` → прогнать через XSD → `Element 'СвПер': Missing child element(s). Expected is ( Контакт )`.
- **Почему не видно в unit-тестах:** в `xsd-validator.test.ts` данные содержат `carrierPhone` явно → тест зелёный. Баг проявляется только при отсутствии телефона перевозчика.
- **Направление фикса:** `renderContact` должен требовать телефон через `req(phone, 'перевозчик: телефон (XSD обязателен)')` → честный 422, либо убрать fallback на `<Адрес>` для участников с типом `СвПер`. Тип `УчастникТрНТип` по XSD ВСЕГДА требует `<Контакт>`.
- **Роутинг:** → /transpult

> **✅ ИСПРАВЛЕНО (TransPult):** `renderContact` теперь всегда пишет `<Контакт>` с
> обязательным телефоном (`req()` → 422), fallback на `<Адрес>` убран. В routes
> `/etrn` телефон перевозчика берётся от пользователя-инициатора (`users.phone`).
> Emit-образец `etrn-t01` дополнен `carrierPhone`. Добавлены 2 регресс-теста
> (генератор без телефона перевозчика/грузоотправителя → `EtrnIncompleteError`).
> **Повторная независимая проверка: 14/14 validates** (26 тестов зелёные). Коммит — ниже.
