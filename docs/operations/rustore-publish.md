# Публикация приложения водителя в RuStore

Пошагово: как выложить мобильное приложение **ТрансПульт.Водитель**
(`tms-driver`, package `ru.transpult.driver`, Expo/EAS) в **RuStore** —
российский магазин приложений (VK), без Google-аккаунта и Google Play.

RuStore принимает и **APK**, и **AAB**.

---

## 0. Что понадобится
- Учётная запись **RuStore Консоль**: <https://console.rustore.ru>
- Юр-лицо или ИП организации (ИНН/ОГРН) — для аккаунта разработчика.
- Собранный релизный артефакт приложения (APK или AAB), подписанный релизным ключом.
- Иконка 512×512, минимум 2–4 скриншота экрана телефона, тексты.
- URL политики конфиденциальности (например `https://transpult.ru/legal/privacy`).
- Контакт поддержки (например `support@transpult.ru`).

---

## 1. Регистрация разработчика
1. Зайти на <https://console.rustore.ru>, войти (VK ID / Госуслуги).
2. Создать **профиль компании**: реквизиты ЮЛ/ИП, подписать оферту.
3. Дождаться подтверждения профиля (обычно быстро).

## 2. Собрать релизный артефакт (EAS)
```bash
# AAB для стора (профиль production в eas.json уже настроен на app-bundle):
pnpm --filter @tms/mobile exec eas build -p android --profile production
# RuStore принимает и APK — при необходимости временно поставить buildType: "apk".
```
- Артефакт скачать со страницы сборки на **expo.dev**.
- ⚠️ **Релизный ключ (keystore)** EAS хранит у себя — сохрани/зафиксируй его.
  Все будущие обновления должны быть подписаны **тем же** ключом, иначе RuStore
  отклонит апдейт.

## 3. Создать приложение в RuStore Консоль
1. **«Добавить приложение»** → загрузить APK/AAB. Консоль сама определит package
   `ru.transpult.driver` и versionCode (сейчас `1`, см. `apps/mobile/app.json`).
2. Заполнить карточку:
   - **Название:** ТрансПульт.Водитель
   - **Краткое и полное описание** (что делает: маршруты, документы, подпись, офлайн).
   - **Категория:** Бизнес / Транспорт.
   - **Возрастной рейтинг:** заполнить анкету (контента 18+ нет → 0+/3+).
3. **Графика:** иконка 512×512, скриншоты (телефон), при желании — баннер.
4. **Юридическое:**
   - ссылка на **политику конфиденциальности** (обязательно);
   - контакт поддержки (email).
5. **Разрешения:** RuStore спросит обоснование «чувствительных» разрешений.
   Указать честно: **геолокация** (трекинг рейса), **камера** (фото ТТН),
   **уведомления** (статусы рейса). Для фоновой геолокации — короткое пояснение,
   зачем она нужна (контроль маршрута перевозки).

## 4. Версия и отправка
1. Указать `versionName` (`0.1.0`) и `versionCode` (`1`).
2. Отправить релиз **на модерацию**.

## 5. Модерация
- Обычно **1–3 рабочих дня**.
- Могут вернуть с замечаниями (описание разрешений, политика, скриншоты) —
  поправить и переотправить.
- После одобрения — публичная страница вида
  `https://www.rustore.ru/catalog/app/ru.transpult.driver`.

## 6. Подключить к сайту
- Когда получишь RuStore-ссылку — на экране `/driver-app` можно **заменить или
  добавить** рядом с прямым APK кнопку/QR на RuStore. Это правка одной константы
  `APK_PATH` (+ при желании бейдж RuStore) — скажи, поменяю.

## Обновления
1. Поднять `versionCode` в `app.json` (`android.versionCode`), при нужде `version`.
2. Собрать новый артефакт (EAS), подписать **тем же** ключом.
3. Загрузить в ту же карточку → модерация → авто-обновление у пользователей.

## Заметки
- RuStore — РФ-стор, **без Google Play / Google-аккаунта**. То, что нужно в РФ.
- Можно держать **два канала** одновременно:
  - прямой APK (`https://transpult.ru/storage/public/tms-driver.apk`) — для
    быстрой раздачи здесь и сейчас (экран `/driver-app`);
  - RuStore — для «солидности» и автообновлений.
- iPhone в RuStore нет (только Android). Для iOS — отдельный путь
  (нативная сборка через Apple Developer либо Telegram Mini App).
