# Project Audit — 2026-05-10

> **Snapshot date: 2026-05-10.** Most findings here have been actioned in subsequent rounds. For a fresher walkthrough see [`audit-2026-05-12-deep.md`](audit-2026-05-12-deep.md).

Comprehensive read of API, web, mobile, infra, and CI. ~171 TS/TSX files, ~194 routes, 50 DB tables, 13 migrations.

## Stack snapshot

Fastify 5 + Drizzle + Postgres + Redis + BullMQ + S3 / Next 15 + React 19 / Expo + WatermelonDB.

## Strengths

- Append-only DB triggers on events / med_inspections / tech_inspections / med_access_log
- CASL RBAC with explicit MedInspectionDetails restriction even for admin
- Entity-level guards (apps/api/src/auth/guards.ts) for org + ownership checks
- Fail-fast on missing JWT_SECRET / DATABASE_URL / REDIS_URL
- Multi-stage Dockerfiles, non-root containers, Next.js standalone output
- Login rate limiting, separate short-lived WS token
- Org-isolation present in auth/users, tariffs, invoices, and entity guards

### New audit additions (post-Round-7)

Discovered while implementing later rounds, none yet critical:

- **A-1 (P3)** — `apps/web/src/middleware.ts` doesn't verify `iss`/`aud` claims, only signature + exp. Low impact on single-deploy systems, would matter for multi-tenant SSO.
- **A-2 (P3)** — Web has no Sentry/Glitchtip integration. Errors only land in browser console + server stderr. Roadmap Phase 1.2 covers it.
- **A-3 (P2)** — Image URLs from lazyweb references have 1-hour signed TTL. Не сохраняем; review notes lose embedded references quickly. Mitigation в [lazyweb-workflow.md](lazyweb-workflow.md) — snapshot top 3 to /tmp.
- **A-4 (P2)** — `apps/api/src/integrations/mocks/*.mock.ts` has no `MOCK_MODE` env-gating safety. If real provider creds + mock both present, order-of-import determines which wins. Recommendation: guard each mock import with `if (process.env.MOCK_MODE === 'true')`.
- **A-5 (P3)** — Mobile `BottomSheet` built but unused; should either wire или delete to prevent code-rot.
