# Project Audit — 2026-05-10

Comprehensive read of API, web, mobile, infra, and CI. ~171 TS/TSX files, ~194 routes, 50 DB tables, 13 migrations.

## Stack snapshot

Fastify 5 + Drizzle + Postgres + Redis + BullMQ + S3 / Next 15 + React 19 / Expo + WatermelonDB.

## Strengths

- Append-only DB triggers on events / med_inspections / tech_inspections / med_access_log
- CASL RBAC with explicit MedInspectionDetails restriction even for admin
- Entity-level guards (apps/api/src/auth/guards.ts) for org + ownership checks
- Fail-fast on missing JWT_SECRET / DATABASE_URL / REDIS_URL
- Multi-stage Dockerfiles, non-root containers, Next.js standalone output
- Login rate limiting, separate short-lived WS token
- Org-isolation present in auth/users, tariffs, invoices, and entity guards
